HarryShop – E-Commerce Database Design & Analytics

Overview

HarryShop is a fictional e-commerce merchandise platform designed for developers and coding enthusiasts. The store offers products such as hoodies, mugs, stickers, notebooks, and tech accessories.

This project showcases the fundamentals of relational database management and SQL-based business analytics using MySQL.

Project Objectives

The project demonstrates:

1.Relational Database Design
2.Entity Relationship Management
3.Implementation of Primary & Foreign Keys
4.Data Normalization Concepts
5.Realistic Sample Data Handling
6.SQL Queries for Business Analytics
7.Database Schema

The database consists of the following tables:

1. Customers – Stores customer information
2. Products – Contains product details and pricing
3. Orders – Manages customer orders
4. Order_Items – Tracks products included in each order
5. Payments – Stores payment transaction details

Key Features :

1. Structured relational database architecture
2. Proper table relationships using foreign keys
3. Sample e-commerce workflow implementation
4. Analytical SQL queries for business insights
5. Analytics & Reporting Queries

The project includes SQL queries for:

* Total Revenue Calculation
* Revenue Generated by Each Product
* Top Customers by Spending
* Best-Selling Products
* Cancelled Orders Analysis
* Technologies Used
* MySQL

Learning Outcomes

Through this project, the following concepts were implemented and practiced:

1. Database schema creation
2. Data relationships and constraints
3. Query optimization basics
4. Aggregate functions and joins
5. Business-oriented SQL analytics
